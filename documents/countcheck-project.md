# CountCheck portfolio entry

2 November 2026.

CountCheck is the first project in the homepage project grid and has its own `/project/CountCheck` detail page. Its live action opens https://countcheck.embarko.app/ and its source action opens https://github.com/VJ-veshwikjain2215/CountCheck.

The description and technology list come from CountCheck's current repository README: private inventory workspaces, searchable products, count reconciliation, safe retries, history and CSV exports, with Java 21, Spring Boot 4.1, Thymeleaf, Spring Security, PostgreSQL, JDBC and Flyway. Count records are manual observations and do not automatically change inventory.
